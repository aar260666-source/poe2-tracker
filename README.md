# PoE2 Tracker Bot

Трекер персонажей для Path of Exile 2: отслеживание лиг, ладдеров и прогресса персонажей.

## 🧠 О проекте

Проект позволяет:

- Регистрация и авторизация на базе JWT‑токенов: профиль создаётся при регистрации, доступ к защищённым эндпоинтам — по Bearer‑токену.
- Получать список актуальных лиг PoE2 (через парсинг страницы ладдера с помощью Playwright с учётом robots.txt и условий использования).
- Добавлять персонажей для отслеживания.
- Получать статистику и позиции в ладдере(соседа сверху, соседа снизу).
- Кэшировать данные и использовать распределённые блокировки через Redis.
- Есть фронтенд для наглядности.

Стек технологий: **Python 3.11+**, **FastAPI**, **SQLAlchemy (async)**, **Redis**, **Playwright**, **Docker**.
